Selected work

Mandelbrot Deep Zoom
A graphics processing unit (GPU) renderer that descends 33 decades into the Mandelbrot set, written in Rust and WebGPU Shading Language (WGSL) and run from one source across a multi-cloud fleet: local Apple Silicon alongside rented NVIDIA on two cloud providers, sharded by cost. Perturbation with exponential-map strips, so the plane is rendered once in log-polar form rather than once per frame. The result is Falling Into Scepter Valley: 5,510 frames, 3:04 at 4K30, ending on a 634 pixel minibrot.
